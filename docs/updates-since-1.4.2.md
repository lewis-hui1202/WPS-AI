# 1.4.2 之后更新清单

范围：1.4.2 之后至当前 1.4.4 代码包。

## 新增功能

### 素材库与素材复用

- ~~素材库支持「项目标签 + 内容标签」，生成图片后可自动生成内容标签。~~
- ~~做文档或 PPT 时，AI 可以按标签、项目、类型、关键词检索并复用素材库内容。~~
- ~~素材库支持导入本地图片，并可调用视觉模型自动打标。~~
- ~~素材库新增文本搜索、项目筛选、标签展示。~~
- ~~素材条目扩展为多来源模型，支持 generated / local / web / image 等来源类型。~~
- ~~新增 `query_materials` 工具，AI 可主动查询素材库。~~
- ~~新增网页抓取能力，可把网页正文作为素材保存。~~
- ~~新增联网找图能力，可把网络图片作为素材保存。~~
- ~~素材预览支持滚轮缩放。~~
- ~~生成图支持在素材库中框选裁剪，并保存为新素材。~~
- ~~素材库布局改为瀑布流，更适合浏览大量图片。~~

### AI 生图、抠图与局部编辑

- ~~AI 生图支持按单次任务指定图片比例。~~
- ~~图像生成比例可由用户手动覆盖，也可按上下文自动判断。~~
- ~~素材库新增 AI 抠图能力，支持一键去背景。~~
- ~~新增画笔涂抹编辑：可圈定主体后进行局部重绘或抠出主体。~~
- ~~新增本地离线抠图：内置 onnxruntime + isnet 神经网络模型，支持发丝级软边透明 PNG。~~
- ~~本地抠图模型首次使用时按需下载，之后可离线运行。~~
- ~~抠图 / 重绘过程新增可见进度遮罩。~~
- ~~抠图 / 重绘支持取消。~~
- ~~当模型不支持透明背景时，自动降级重试并补成本地透明 PNG。~~

### PPT 生成与演示编辑

- 新增 PPT 分步生成：整套幻灯片先插入占位骨架，快速进入预览状态。
- PPT 配图改为后台异步生成，每页图片齐全后自动替换回对应页面。
- 新增图片槽位解析、占位图生成、配图回填、并发限制、页面就绪追踪等分步生成能力。
- 全套 PPT 生成支持唯一页面标记，用户在前面插入页面后仍能准确回填原页面。
- HTML 模板预览和 PPT 插入流程增强，支持更稳定的异步图片回填。
- PPT 预览历史可继续关联原缓存记录，便于二次修改。

### PDF 阅读、翻译与问答

- PDF 对照翻译、全文总结、PDF 问答重构为双通道。
- 数字版 PDF 优先抽取带页码的文字内容，任意文本模型均可读取，成本更低、页码更准。
- 扫描件 PDF 自动回退为整文件多模态附件。
- 新增 PDF 文件路径探测能力，兼容不同 WPS 版本的 PDF 对象命名差异。
- PDF 对照翻译改为独立窗口。
- PDF 对照翻译支持选择原文语言、目标语言。
- PDF 对照翻译支持全文翻译或指定页码范围翻译。
- PDF 对照翻译结果以流式原文 / 译文对照表呈现。
- PDF 提示词改为明确引用带页码正文，减少模型误判。

### Word 写入与选区操作

- ~~Word 写回改为原生结构化块写入，不再先生成 markdown 再转换。~~
- ~~新增原生标题、段落、列表、表格、代码块、空段落等结构化写入能力。~~
- ~~AI 插入 / 替换工具支持直接接收结构化 blocks。~~
- ~~选区预览确认后会转换为结构化 blocks 再写入 Word。~~
- ~~Ribbon 选区操作会自动结合文档标题、大纲与选区上下文。~~
- ~~扩写、翻译、润色、优化等选区操作更能贴合全文主题、术语和语气。~~
- ~~文档上下文读取增加大纲、标题、选区周边内容，并限制扫描范围以改善性能。~~
- ~~AI 排版相关写入支持 1-6 级标题。~~
- ~~列表写入和替换时保留项目符号 / 编号格式。~~

### Token 消耗统计
